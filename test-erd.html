✅ Test: ERD Rendering with Mermaid

Example 1: Employee Management System

erDiagram
    Employee ||--o{ Attendance : logs
    Employee ||--o{ LeaveRequest : requests
    Employee ||--o{ OvertimeRequest : requests
    Manager ||--o{ Employee : manages
    Role ||--o{ Employee : assigns

    Employee {
        int id PK
        string name
        string email
        int manager_id FK
        int role_id FK
    }

    Attendance {
        int id PK
        int employee_id FK
        date date
        time check_in
        time check_out
    }

    LeaveRequest {
        int id PK
        int employee_id FK
        date start_date
        date end_date
        string status
    }

    OvertimeRequest {
        int id PK
        int employee_id FK
        date date
        float hours
        string status
    }

    Manager {
        int id PK
        string name
        string department
    }

    Role {
        int id PK
        string role_name
        string permissions
    }

Example 2: Blog System

erDiagram
    User ||--o{ Post : writes
    User ||--o{ Comment : makes
    Post ||--o{ Comment : has

    User {
        int id PK
        string username
        string email
        datetime created_at
    }

    Post {
        int id PK
        int author_id FK
        string title
        text content
        datetime published_at
    }

    Comment {
        int id PK
        int user_id FK
        int post_id FK
        text content
        datetime created_at
    }
